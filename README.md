  As a user, I want to have a pet to interact with, like feeding, playing, healing so that I could have joy with it

As a user, I want to check the status of my pet, with hunger, happiness, health so that in case I need to feed,play or heal my pet

As a user, I want to access virtual store so that I can buy stuffs with rewarded coins for my pet 

As a user, I want to record my spending/earning in system so that I can check my finance expense

As a user, I want to customize my daily/weekly/monthly budget limit so that I could suit it in my own pace

As a designer, I want user to get rewarded coins if user is under the budget limit over a period

As a designer, I want the user pet’s condition to change over time, so users need to come back and take care of it.

As a user, I want to name and customize my pet, such as its appearance or accessories so that it feel like I have a real my own pet

As a user, I want to see how much money I have left before reaching my daily/weekly/monthly budget in case I don’t exceed the budget

As a user, I want to see a spending summary by category so that I can understand where my money goes.
As a user, I want to edit or delete a transaction so that I can change it when I enter it incorrectly.

As a user, I want to edit my budget after creating it so that in case I change my mind.

As a user, I want to see my budgeting streak and past achievements.

As a designer, I want different items to affect different pet stats, such as food decreasing hunger level and toys increasing happiness.

As a user, I want to receive an achievement or special item when I reach a financial goal so that it feels like I get rewarded from saving money.

As a designer, I want the data to be saved so the pet, expenses, budget, and coins remain when users reopen the application.

As a user, I want to view my transaction history and filter it by date or category.

As a user, I want the app to warn me when I am close to or over my budget in case I don’t reach the limit.

As a user, I want to choose when my budget cycle starts so that it matches my personal spending or payday schedule.
